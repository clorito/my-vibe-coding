# Vibe Coding 从零开始 · 6 周学习路径（GLM Coding Plan 版）

> Vibe Coding = 你负责「想清楚要什么」，AI 负责写代码，你负责验收和迭代。
> 本课程的核心方法：**每个知识点都通过"和 AI 对话 → 看代码 → 动手改"来学习**，而不是先啃语法书。

## 你的学习装备

- **GLM Coding Plan**：你的 AI 额度包，通过 ZCode（本客户端）使用
- **ZCode**：你正在用的 AI 编程助手，课程全程在它的对话里完成
- 每天的用法：打开 ZCode → 进入对应 stage 的练习文件夹 → 按课程文档里的提示词练习

## 学习路径总览

| 阶段 | 主题 | 时长 | 产出 |
|------|------|------|------|
| Stage 0 | 环境准备 + 第一次 Vibe Coding | 第 1 天 | 跑通第一个网页 |
| Stage 1 | AI 协作基本功（提示词 + 验收） | 第 1 周 | 个人主页网站 |
| Stage 2 | Git 版本控制 + AI 协作规范 | 第 2 周 | 带 GitHub 仓库的项目 |
| Stage 3 | 第一个完整应用（待办清单） | 第 3 周 | 前后端待办应用 |
| Stage 4 | 调试、测试、部署 | 第 4 周 | 上线的在线应用 |
| Stage 5 | 毕业项目（记账/笔记类产品） | 第 5-6 周 | 一个完整的小产品 |

## 每阶段统一节奏（把 Coding Plan 用满）

1. **学（10 分钟）**：读该阶段的 `lesson.md`
2. **仿（20 分钟）**：照着文档里的提示词在 ZCode 里跑一遍，观察 AI 产出
3. **改（30 分钟）**：用「练习卡」里的任务改造样例代码，自己提需求
4. **收（10 分钟）**：对照「验收清单」，让 AI 帮你检查（提示词模板见各阶段文档）

## Coding Plan 额度使用建议

- 学习期每天 30~60 次对话足够，重在**一次把需求说清楚**，减少来回
- 每次开新任务前让 ZCode「先读项目再动手」，能显著减少返工
- 大任务拆小：一次让它做 1 个功能，而不是 5 个
