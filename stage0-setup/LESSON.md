# Stage 0 · 环境准备 + 第一次 Vibe Coding（第 1 天，约 1 小时）

## 目标
- 确认 ZCode + GLM Coding Plan 可用
- 理解 Vibe Coding 的基本循环：**说需求 → 看产出 → 提修改 → 验收**
- 生成并打开你的第一个网页

## 步骤 1：确认环境（5 分钟）
你已经打开了 ZCode（就是现在这个窗口），说明 Coding Plan 已就位。
可以先用一句话测试：

```
你好，请简单介绍一下你能帮我做哪些和编程有关的事情，我是零基础。
```

## 步骤 2：第一次 Vibe Coding（20 分钟）
在本文件夹里，对 ZCode 说：

```
请在当前目录创建一个 hello.html，内容是一个自我介绍的网页：
- 标题是"我的 Vibe Coding 第一步"
- 有一段欢迎文字和一个按钮，点击按钮会弹出"我开始学编程啦！"
- 样式简单好看即可
```

然后在文件管理器双击 `hello.html` 用浏览器打开，点按钮试试。

## 步骤 3：体验"改"的过程（15 分钟）
继续对话（不用重新解释背景，AI 记得上下文）：

```
很好！现在做三个修改：
1. 把页面背景改成浅蓝色
2. 按钮下面加一个显示当前时间的文字
3. 每次点击按钮，标题字号变大一号
```

每改一次就刷新浏览器看效果——这就是 Vibe Coding 的核心循环。

## 步骤 4：让 AI 当老师（10 分钟）
```
刚才这段代码里，用 <script> 标签写了 JavaScript。
请用零基础能懂的话，逐行解释 hello.html 里的 JS 部分在做什么，每行不超过一句话。
```

## 验收清单
- [ ] hello.html 能在浏览器打开
- [ ] 点击按钮有反应
- [ ] 你能说出 HTML / CSS / JS 各自管什么（说不清就问 AI："用做菜打比方解释三者的关系"）

## 常见问题
| 问题 | 怎么办 |
|------|--------|
| 不知道怎么打开生成的文件 | 问 ZCode："告诉我怎么在我的电脑上打开这个文件" |
| 效果和想的不一样 | 直接描述差异："按钮点击后没反应，帮我排查" |
| 想看懂某行代码 | 选中贴给 AI："逐词解释这一行" |
