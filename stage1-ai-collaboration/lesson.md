# Stage 1 · AI 协作基本功（第 1 周，每天 1 小时）

## 目标
学会把需求说清楚、看懂 AI 产出的代码结构、把不满意的地方精准反馈回去。
本周产出：一个 3 个页面的个人主页网站。

## Day 1：好提示词 vs 差提示词

差：「帮我做个网页」
好：「做一个个人主页 index.html，包含：顶部导航（首页/关于/作品）、一段自我介绍、三张兴趣卡片，配色用深色主题，单个 HTML 文件内含 CSS」

**好提示词五要素**：① 做什么（文件/页面）② 有哪些内容 ③ 长什么样（风格）④ 技术限制（单文件/不引依赖）⑤ 给谁用。

练习：用五要素写一段提示词，让 ZCode 在本文件夹生成 `samples/my-homepage.html`，然后打开看效果。

## Day 2：读代码 —— 让 AI 当讲解员

提示词模板：
```
请把 samples/my-homepage.html 分成几个"区块"讲给我听：
1. 整体结构（head / body / script 各管什么）
2. 导航部分用了什么标签，为什么用这些
3. 卡片是怎么排成三列的（讲 CSS 的 display/flex 概念）
每个部分配一个"如果我想改 X，应该动哪里"的例子。
```

然后动手：把三张卡片改成四张，看你会不会自己找到该改哪里。

## Day 3：精准反馈 —— 描述差异，不说"感觉不对"

反馈模板：「功能对，但是 ___（现象）和我预期 ___ 不一样，请修改 ___，保持其他部分不动。」

练习：对生成的主页连续提 3 个修改（换配色 / 加页脚 / 图片变圆角），每次只改一处。

## Day 4：迭代出第二个页面

```
参考 samples/my-homepage.html 的风格，创建 about.html：
- 讲我的学习经历（用时间轴样式）
- 底部有"返回首页"链接，index.html 导航里也要能跳到这个页面
```

## Day 5：小考 —— 不看文档独立完成

需求：给主页加一个 `works.html` 作品页，2×2 网格展示四个"未来想做的项目"卡片，风格统一，三页导航互通。
先自己写提示词，卡住了再看 Day 1 的五要素。

## 验收清单
- [ ] 三个页面风格统一、导航互通
- [ ] 你能指出：改标题动哪里、改颜色动哪里、加卡片动哪里
- [ ] 收藏了 3 个你觉得好用的提示词模板
