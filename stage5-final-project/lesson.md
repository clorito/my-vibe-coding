# Stage 5 · 毕业项目：你的第一个小产品（第 5-6 周）

## 目标
综合运用前四个阶段的能力，独立完成一个可以给真实用户用的小产品。
选题建议（选一个你真的会用的）：
- 💰 记账本：记支出、分类统计、月度图表
- 📝 笔记应用：分类笔记、搜索、标签
- 🍚 习惯打卡：每日打卡、连续天数、统计

## 项目节奏（两周，每步都先让 AI 出计划再动手）

### 第 1 周：从 0 到 1
**Day 1-2 · 产品需求文档（PRD）**
```
我要做一个 <选题>。请采访我 5~8 个问题搞清楚需求，然后帮我写一份简单 PRD，
包含：目标用户、核心功能清单（分必须/可选）、页面清单、数据结构。
```
**Day 3-4 · 技术方案 + 项目骨架**
```
基于这份 PRD，请给出技术方案建议（对新手友好的前后端选型），
搭好项目骨架，让项目先能跑起来（哪怕只有一个空首页）。
```
**Day 5 · 数据层**
先做数据存储和 API（参考 Stage 3 的做法），用浏览器直接访问 API 验证。

### 第 2 周：功能 + 打磨 + 上线
**Day 6-8 · 核心功能**
每次只做一个功能：开发 → 手动验收 → 让 AI 跑测试 → commit。
**Day 9 · 统计/图表**
让 AI 加一个数据可视化（如 Chart.js 月度支出图）。
**Day 10 · 打磨**
```
请以产品经理的视角审查我的应用，列出 5 个最影响体验的问题并修复。
```
**Day 11 · 测试 + 部署**
复用 Stage 4 的流程：自动化测试 → 部署上线。
**Day 12 · 发布 + 复盘**
发给 3 个朋友用，收集反馈改一版。最后让 AI 帮你复盘：
```
请根据 git log 总结我这个项目的开发历程，并点评我作为 Vibe Coder 的成长点。
```

## starter/ 说明
`starter/prd-template.md`：PRD 模板，Day 1 直接让 AI 基于你的填写展开。

## 毕业验收清单
- [ ] 有 PRD 和 Git 提交历史（20+ 次小步提交）
- [ ] 至少 5 个核心功能可用，有自动化测试
- [ ] 已部署上线，朋友能访问
- [ ] 你能不看资料说出：需求 → PRD → 骨架 → 功能 → 测试 → 上线 的完整流程

## 毕业之后
- 把课程产出整理进 GitHub 仓库当作品集
- 进阶方向：让 AI 给你讲「MCP / 工具调用 / 多文件重构」——此时你已经具备理解它们的经验了
