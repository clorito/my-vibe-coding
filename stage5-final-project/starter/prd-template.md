# 产品需求文档（PRD）模板

> 用法：填好本模板后对 ZCode 说「这是我的 PRD，请基于它制定实现计划」。

## 1. 一句话描述
我的产品是 __________，帮 __________（谁）解决 __________（什么问题）。

## 2. 目标用户
- 主要用户：__________
- 使用场景：__________（什么时候/在哪里用）

## 3. 功能清单
### 必须有（第一版就要）
- [ ] __________
- [ ] __________
- [ ] __________

### 可以有（时间够再做）
- [ ] __________

### 明确不做（防止范围膨胀）
- __________

## 4. 页面清单
| 页面 | 作用 | 包含元素 |
|------|------|----------|
| 首页 | | |
| | | |

## 5. 数据结构（可以先空着，让 AI 帮你设计）
- 核心对象：__________，字段：__________

## 6. 风格与限制
- 视觉风格：__________（如：简洁浅色 / 深色 / 活泼）
- 技术限制：__________（如：新手友好选型、免费部署）

## 7. 验收标准（怎么算做完）
- [ ] __________
- [ ] 朋友能在 1 分钟内上手，不用我教
